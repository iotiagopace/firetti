# BIOPHARCOS — rodada completa

Este pacote organiza o conteúdo público identificado em https://www.maxup.com.br/bst/

Inclui:
- BIOPHARCOS_conteudo_estruturado.md
- biopharcos_content.json
- paginas.csv
- produtos.csv
- contatos.csv
- assets_mapeados.csv
- baixar_originais.py

Páginas confirmadas:
1. Início
2. Quem somos
3. Terceirize sua Produção
4. Linha de Produtos
5. Fale Conosco

Observações:
- O vídeo institucional está anunciado no site como "Em breve disponível".
- Foram mapeadas 7 imagens de conteúdo expostas diretamente pelo rastreamento público.
- O ambiente da conversa não conseguiu baixar os binários do domínio maxup.com.br, então os URLs originais estão preservados no manifesto.
- O script baixar_originais.py permite fazer o arquivamento direto da origem em um ambiente com acesso ao domínio.
- Textos longos estão estruturados/condensados para migração, mantendo o sentido, as seções, produtos, claims, formulários e dados públicos identificados.
